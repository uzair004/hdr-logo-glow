The 4,000-nit avatar

Haladir's LinkedIn logo does not look bright. It is bright — the file instructs the display to emit roughly 4,000 cd/m² where every other pixel on the page sits at 203. This page is the teardown of their actual file, byte for byte, and the reference the algorithm.io decision is measured against.

Evidence

I pulled the logo from LinkedIn's CDN and decoded it. It is an ordinary progressive JPEG with one unusual passenger: a 9,196-byte ICC colour profile carrying a 12-byte cicp tag.

The widely-shared LinkedIn post calls this “EXIF data”. It isn't — it's an ICC profile in the JPEG's APP2 marker. That distinction is the whole trick: social pipelines strip EXIF and gain-map metadata, but they preserve ICC profiles. The payload rides through LinkedIn's re-encode intact.

Mechanism

An SDR image is relative. Code 255 means “reference white”, and macOS renders reference white at about 203 nits. An XDR panel physically reaches 1,000–1,600. The unused gap is called headroom.

A PQ image is absolute. Under SMPTE ST 2084 a code value names a real luminance on a 0–10,000 cd/m² scale. Once the file carries cicp 9/16/0/1, code 232 stops meaning “light grey” and starts meaning 4,000 nits. The compositor obeys, clamps to what the panel can emit, and drives those pixels into the headroom while the rest of the page stays pinned at 203.

Nothing is glowing. The logo is at panel maximum and everything around it is at a fifth of panel maximum. It is simultaneous contrast, weaponised.

The ladder

The same artwork encoded at rising target luminance, with Haladir's real file at the end. Change the surround — the effect depends heavily on what sits next to it.

Past roughly 1,600 the panel cannot follow, so the extra headroom buys diminishing brightness and increasing risk of a flat, clipped slab. 4,000 is the point where it still rolls off gracefully.

The shimmer

The detail nobody copies

Haladir's field is not a flat white slab. I checked whether the mottling was JPEG noise: it isn't. Low-frequency structure spans 16 code values — about 600 nits of slow organic veining — while high-frequency noise measures only σ = 2.2. Structure beats noise seven to one.

structure spread 16 code valuesjpeg noise σ 2.2ratio 7 : 1

That variation is why the tile reads as lit material rather than a blown-out rectangle. It is the difference between a lamp and an error.

Fragility

One CSS declaration defuses the entire technique. Below are the same files with dynamic-range-limit: standard applied — shipping in Chrome 136+ and Safari 26+.

  • Screenshots don't carry it. macOS tone-maps to SDR on capture, so 4,000 nits collapses back to plain white. You cannot show this in a deck.
  • Slack already patched it. Instagram wants gain maps instead. LinkedIn is currently the one surface where it reliably lands.
  • It is genuinely aggressive. Night browsing, photosensitivity and migraine are real costs. Haladir gets away with it because the mark is black-on-light, so there is no glare over text.
